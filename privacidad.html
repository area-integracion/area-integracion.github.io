Política de Privacidad

Área de Integración · Última actualización: 3 de noviembre de 2026

Esta política explica cómo Área de Integración trata los datos utilizados para organizar actividades y gestionar reservas de asesorías desde area-integracion.github.io.

1. Información que tratamos

Para administrar asesorías, podemos tratar los datos proporcionados al realizar una reserva, como nombre, información de contacto, instructor elegido, fecha, hora y estado de la reserva. Para los instructores, también podemos gestionar datos de cuenta, disponibilidad y permisos de acceso.

2. Finalidades

Utilizamos estos datos para registrar y confirmar asesorías, mostrar las reservas a los usuarios autorizados, administrar horarios, comunicar cambios y mantener el funcionamiento y la seguridad de la plataforma. No vendemos datos personales.

3. Integración con Google Calendar

La conexión directa con Google Calendar API está prevista como una función opcional para instructores y aún se encuentra en desarrollo. Cuando esté disponible, cada instructor deberá autorizar expresamente la conexión de su propia cuenta de Google.

Esta integración se diseñará para crear, actualizar y cancelar únicamente los eventos de asesoría gestionados por Área de Integración. La plataforma no utilizará la integración para consultar, recopilar, analizar ni compartir eventos personales ajenos a las asesorías. Los permisos técnicos solicitados se limitarán en la medida que permita Google al funcionamiento necesario; no se utilizarán para otros fines.

La información recibida de las API de Google se utilizará conforme a la Política de Datos del Usuario de los Servicios de las API de Google, incluidos sus requisitos de Uso Limitado.

4. Acceso y terceros

Los datos de reservas se almacenan y procesan mediante servicios de infraestructura, incluido Supabase. Solo las personas autorizadas dentro de la plataforma deben acceder a los datos necesarios para su función. Google procesará la información de los eventos creados en el calendario del instructor conforme a sus propias condiciones y políticas.

5. Seguridad y conservación

Aplicamos controles de acceso para proteger los datos de las reservas. Conservamos la información mientras sea necesaria para la gestión del servicio, el cumplimiento de obligaciones aplicables y la resolución de incidencias. Revisaremos y concretaremos los plazos de conservación conforme evolucione el servicio.

6. Control de la conexión de Google

Cuando se habilite la conexión directa, los instructores podrán retirar la autorización desde la configuración de seguridad de su cuenta de Google. También se habilitará un mecanismo para desconectar la integración desde la plataforma. Retirar el permiso impedirá futuras sincronizaciones hasta que se vuelva a autorizar.

7. Derechos y consultas

Las personas pueden solicitar información, acceso, rectificación o eliminación de sus datos, según la legislación aplicable, escribiendo a simarq97@gmail.com. Se podrá solicitar información adicional para verificar la identidad del solicitante antes de atender una petición.

8. Cambios en esta política

Podemos actualizar esta política cuando cambien las funciones de la plataforma o las obligaciones legales. Publicaremos la versión vigente en esta misma página.

Importante: La publicación de esta política no significa que la conexión directa con Google Calendar API ya esté activada. Esa función requerirá configuración, desarrollo y pruebas adicionales.
